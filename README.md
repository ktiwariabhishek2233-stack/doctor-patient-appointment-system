# MediConnect - Doctor-Patient Appointment Management System

College Project Frontend for FA-2 Demonstration.

## 🚀 Features

- **Landing Page**: Brand logo, Hero "Your Health, Our Priority", Find a Doctor CTA, 4 core feature cards, Patient/Doctor capability breakdown, and clean footer.
- **Auth Page**: Single `Auth.jsx` with Login/Register tab switch, Role selection (Patient/Doctor), registration fields, and fast one-click demo login buttons.
- **Patient Portal**: Search doctors by name & specialization, view doctor slots (with booked slots disabled), book appointments with reason (sets status to PENDING), track appointment history timeline (PENDING/ACCEPTED/REJECTED/COMPLETED), upload medical reports (PDF/JPG/PNG), and edit patient profile.
- **Doctor Workstation**: Manage slots (add date/time slots, delete open slots; booked slots disabled from deletion), view incoming appointment requests, ACCEPT (PENDING → ACCEPTED) or REJECT (PENDING → REJECTED) requests, view patient medical reports, and edit doctor profile.

## 🛠️ Built With

- **HTML5 & CSS3**: Pure CSS styling inside single `src/index.css`.
- **React.js (JSX)**: Component state management & reactivity.
- **React Router DOM**: Client-side routing.
